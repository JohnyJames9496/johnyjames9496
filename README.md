### Customer Churn Predictor
Production-grade ML system that predicts whether a telecom customer will churn. Trained and compared four models — Logistic Regression, Decision Tree, Random Forest, XGBoost. Applied SMOTE to handle class imbalance. Final model achieved ROC-AUC of 80.99%. Fully Dockerized with a FastAPI backend and Streamlit frontend.

**Stack:** Python, Scikit-learn, XGBoost, FastAPI, Streamlit, Docker, Pandas, NumPy

**Model Performance:** Accuracy 76.19% · Recall 65.78% · ROC-AUC 80.99%

**GitHub:** [churn-predictor](https://github.com/JohnyJames9496/churn-predictor)
